# Frontend Agrotis

Aplicação React + TypeScript + Vite para gestão de produtores, propriedades e laboratórios, dashboard e monitoramento da integração.

```bash
npm ci
npm run dev
npm run build
npm run lint
```

O backend deve estar disponível em `http://localhost:8080`. Para outra URL, defina `VITE_API_BASE_URL`. Para arquitetura e instruções de Docker, integração, API e financeiro, consulte o [README da raiz](../README.md).
